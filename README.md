# Island Escape — Bali Travel Destination Website

A responsive, single-page travel destination website built with HTML, CSS and vanilla JavaScript.

## Included
- Hero section with destination photography
- Places to visit: Ubud, Uluwatu and Nusa Penida
- Three sample travel packages
- Activities and experiences section
- Booking/enquiry form with basic validation and on-page confirmation
- Responsive mobile navigation and layouts

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the remote Unsplash photos and Google Fonts.

## Customize
- Edit text, destinations, package details and form fields in `index.html`.
- Change colours, spacing and responsive styles in `styles.css`.
- Update menu and form behaviour in `script.js`.

## Note
This is a front-end demo. The booking form does not send data to a server, take payment or create a real reservation. Package prices are illustrative estimates.
